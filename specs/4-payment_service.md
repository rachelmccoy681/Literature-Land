Requirement 7: Complete Order

FR07 – Complete Order 
Description:
The system shall allow customers to review their shopping cart and complete an order for the selected books. 
User Story:
As a customer, I want to complete an order so that I can purchase the books I have selected. 
Rationale:
Completing an order is a core function of the online bookstore and allows customers to finalise their selected purchases. 
Acceptance Criteria:
A customer with valid items in their cart can successfully place an order and receive confirmation that the order has been created. 
Priority:
High

Requirement specification

## Description:
The system shall allow customers to review their shopping cart and complete an order for the selected books. 


## User Story:
As a customer, I want to manage books in my shopping cart so that I can control which books and quantities I intend to purchase. 
As a customer, I want to view and sort through each book in my cart, so i can view everything at-a-glance before i purchase the items.

## Rationale:
A shopping cart allows customers to temporarily store and review selected books before completing an order.
